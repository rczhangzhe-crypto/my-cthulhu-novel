# 故事圣经

状态标签原样保留；本文件不将计划或未决项提升为正典。

# 1. Project Overview

## Core Genre
[CONFIRMED]
- 长篇网络小说。
- 核心类型为：克苏鲁神话 / 宇宙恐怖 + 中国古文化 / 术数体系 + 历史悬疑 + 近未来科幻 + 双时间线叙事。
- 世界观将克苏鲁神话、中国八卦五行术法、奇门遁甲、梅花易数、二十八星宿、《山海经》妖兽等体系结合。
- 主要时代跨度在 20 世纪新英格兰地区与 2026—2048 年左右的现代 / 近未来之间。
- 小说计划共八卷，对应八卦，顺序从坤开始，以乾结束。
- 整体意象为“天地逆位”“否极泰来”“由地至天”“由生命、物质逐步进入信息、时间、恒星、梦境、混沌与创世”。

## Narrative Features
[CONFIRMED]
- 第一卷采用 1928 / 2026 双线交叉叙事。
- 1928 与 2026 之间存在顾观澜与陈济明的身体—意识互换。
- 八卷不仅是卷名，也计划作为整部作品的叙事结构。
- 各卷内部使用以该卷上卦为核心的一组六十四卦子结构推进。
- 卷与卷之间通过前一卷终卦与下一卷起卦形成结构衔接。
- 已明确举例：
  - 第一卷末：地山谦。
  - 第二卷初：山地剥。
  - 坎卷内部可从水山蹇等坎上卦的卦象推进至水风井。
- 二十八星宿与“二十八处封印 / 灾星归位”相关。
- 2048 年左右为“群星归位”大事件的重要时间节点。
- 伊斯伟大种族不是反派；其提前观测到 2048 群星归位与旧日支配者复苏，因此进行布局，帮助主角获得改变历史 / 可能性的机会。

## Core Direction
[CONFIRMED]
- 主角陈济明不是开局即拥有强大术法。
- 第一卷阶段，陈济明只会梅花易数用于占吉避凶，成功率不高。
- 故事推进不是简单“打怪升级”，而是逐渐发现：
  - 异常事件彼此相关。
  - 敦威治事件并非孤例。
  - 古代 / 远古就存在类似以灵长类或人类作为胚胎 / 温床、供外神或相关存在降生的现象。
  - 二十八宿封印的变化与 2048 群星归位存在系统性关系。
- 长期目标是阻止 2048 群星归位后旧日支配者全面复苏的终局。

# 2. Confirmed Canon

## [CONFIRMED] Main Protagonist
- 姓名：陈济明。
- 时代：2026 年正常时间线。
- 身份：赴美留学生。
- 开局能力：只会梅花易数，用于占吉避凶；成功率并不高。
- 开篇在乘坐 MBTA 火车时卷入首个异常事件“常暗之厢（现代版）”。
- 事件结束后，原以为能够返回现实，打开车门后却进入 1928 年，并与顾观澜发生身体—意识互换。
- 第一卷 1928 线：
  - 身体：顾观澜。
  - 意识：陈济明。
- 第一卷 2026 线：
  - 身体：陈济明。
  - 意识：顾观澜。
- 第一卷末 / 后段：
  - 陈济明意识回到自己的 2026 身体。
  - 顾观澜意识回到自己的 1928 身体。
- 第二卷开头：
  - 陈济明回到现代后，对自己与顾观澜互穿身体一事有更明确认知。
  - 得知更多隐秘。
  - 发现林栖迟有意避开自己。

## [CONFIRMED] 顾观澜
- 1928 年人物。
- 第一卷中与陈济明发生意识—身体互换。
- 第一卷 1928 线：
  - 身体是顾观澜。
  - 身体中的意识主要为陈济明。
- 第一卷 2026 线：
  - 顾观澜意识位于陈济明身体中。
- 顾观澜在 2026 年经过林栖迟、周衡等人帮助，摆脱 FBI 或相关异常事件处理组织的问询。
- 顾观澜在 2026 年与候时会北美分部建立联系。
- 顾观澜在现代查找历史中有关敦威治事件的记载，并得知自己及同行人员的相关经历。
- 通过某些尚未确定的手段辅助解密 / 促成双线解决。
- 在陈济明返回自己身体后，顾观澜回到 1928 年自己的身体中。
- 顾观澜回到 1928 后建立候时会北美分部。
- 候时会北美分部后来存在与林栖迟祖辈有关的家族 / 传承。
- 顾观澜留下《无日历》。
- 《无日历》中记录了“常暗之厢”等一系列异常。

## [CONFIRMED] 林栖迟
- 2026 年核心角色。
- 是“常暗之厢”同行乘客之一。
- 在第一卷现代线中帮助处于陈济明身体中的顾观澜。
- 与周衡等人协助顾观澜摆脱 FBI 或相关异常事件处理组织的问询。
- 与候时会北美分部 / 其历史家族存在关联：
  - 顾观澜 1928 年建立的候时会北美分部中，后来分部家族中有林栖迟的祖辈。
- 第二卷开头，陈济明发现林栖迟有意避开自己。
- 是否为女主之一：尚未最终确定。

## [CONFIRMED] 周衡
- 2026 年角色。
- 与林栖迟一起帮助处于陈济明身体中的顾观澜。
- 协助其摆脱 FBI 或相关异常事件处理组织的问询。
- 其他身份、能力、关系尚未确认。

## [CONFIRMED] 沈砚秋
- 1928 年线重要人物。
- 与陈济明（位于顾观澜身体中）、米斯卡托尼克大学、候时人 / 相关组织共同处理第一卷敦威治事件。
- 第二卷开头前，陈济明还会联合 1928 年的候时人（中华总部 / 当时更接近钦天监形态）解决相关事件。
- 沈砚秋的详细身份、能力、动机未最终确认。

## [CONFIRMED] 伊斯伟大种族
- 不是反派。
- 提前观测到约 2048 年“群星归位”。
- 它们已观察到：
  - 二十八宿 / 封印系统走向失效或复位。
  - 旧日支配者全面复苏。
  - 该事件是人类 / 地球文明的重大终局灾难。
- 因此提前布局。
- 伊斯伟大种族通过某种方式：
  - 将一套能够变化成跑团骰子的神器交给主角。
  - 引导陈济明在故事开端发生时间穿梭 / 与顾观澜互换身体。
  - 使陈济明来到群星归位事件链条更早的起点。
  - 其目的在于阻止怪物 / 旧日支配者最终复苏。
- 神器的正式名称、机制与完整限制尚未确认。

## [CONFIRMED] 候时会
- 是故事中的重要组织。
- 存在中华总部。
- 1928 年时期，中华总部形态“更接近钦天监”。
- 顾观澜在经历 2026 后返回 1928，建立候时会北美分部。
- 2026 年北美分部已经存在。
- 北美分部历史中有林栖迟祖辈所属家族 / 传承。
- 2026 年顾观澜与北美分部建立联系。
- 候时会与《无日历》、时间异常、异常事件调查存在直接关系。
- 具体组织结构、门规、权力层级尚未确认。

## [CONFIRMED] 《无日历》
- 由顾观澜在 1928 年后留下。
- 是候时会北美分部的重要记录。
- 记录“常暗之厢”等一系列异常事件。
- 在 2026 年，顾观澜可通过候时会北美分部接触历史记录，从而得知自己与同行人员的相关经历。
- 《无日历》在第一卷双线解密中具有重要作用。
- 其具体物理形式、书写机制、是否包含未来文字等尚未确认。

## [CONFIRMED] 常暗之厢
- 第一卷开篇异常事件。
- 现代版发生在 2026 年 MBTA 火车 / 车厢中。
- 陈济明与同行乘客（其中包括林栖迟）卷入。
- 解决事件后，陈济明以为可以回到现实。
- 打开车门后，发生时间 / 身份异常，最终使陈济明进入 1928 年顾观澜身体。
- 该事件与伊斯伟大种族的布局有关。
- 顾观澜日后会在《无日历》中记录“常暗之厢”。
- 具体规则、怪物、空间机制、事件细节尚未确认。

## [CONFIRMED] 2048 群星归位
- 大约发生于 2048 年。
- 与二十八星宿封印系统有关。
- 28 星宿代表 28 处封印。
- 当相关封印被破坏 / 复位到某种危险状态时，28 灾星逐步归位。
- 克图格亚是这些“灾星 / 归位体系”中明确提到的存在之一。
- “群星归位”意味着旧日支配者们将醒来。
- 伊斯伟大种族提前观测到这一未来，并据此展开布局。

# 3. Story Premise

## [CONFIRMED] Opening Premise
- 2026 年，赴美留学生陈济明乘坐 MBTA 火车。
- 他意外卷入“常暗之厢”。
- 他与同行乘客共同解决事件。
- 陈济明原以为可以回到现实。
- 当他打开车门后，却进入 1928 年顾观澜的身体。
- 同时，顾观澜的意识进入 2026 年陈济明的身体。
- 两条时间线由此并行推进。

## [CONFIRMED] Volume One Core Conflict
- 1928：
  - 陈济明（意识）+ 顾观澜（身体）
  - 联合米斯卡托尼克大学、沈砚秋、候时人及相关组织
  - 处理 / 阻止“敦威治恐怖事件”改编版事件。
- 2026：
  - 顾观澜（意识）+ 陈济明（身体）
  - 经林栖迟、周衡帮助
  - 摆脱 FBI 或异常事件处理机构问询
  - 联系候时会北美分部
  - 查找历史中的敦威治事件记录
  - 得知自己和同行人员经历
  - 对 1928 线进行辅助解密 / 支援。
- 最终两人意识回到各自身体。
- 顾观澜回 1928 后创建候时会北美分部，并留下《无日历》。

## [CONFIRMED] Long-Term Conflict
- 敦威治事件只是更大事件链的起点之一。
- 第二卷开始，现代候时会监测到南极某处冰山 / 冰体异常剥离。
- 该异常衔接《疯狂山脉》式剧情，但重写为 2026 科技背景下的现代版本。
- 调查逐渐揭示：
  - 敦威治案例并非唯一。
  - 古代、远古就有类似人类 / 灵长类被培育为外神降生温床的事件。
  - 昆仑、山海经、疯狂山脉、星宿封印等属于同一更大体系的不同切面。
- 终极威胁为 2048 左右群星归位、二十八灾星归位、旧日支配者复苏。
- 伊斯伟大种族希望通过陈济明的行动阻止这一结果。
