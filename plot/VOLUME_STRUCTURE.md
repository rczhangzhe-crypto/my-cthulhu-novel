## Volume 2 — 艮
[CONFIRMED]
- 对应：
  - 《疯狂山脉》。
  - 昆仑。
  - 西王母。
  - 《山海经》山经。
- 现代背景：2026 版本，使用现代科技 / 南极科考背景重构。
- 起卦：山地剥。
- 已确认整体推进：
  山地剥 → 山泽损 → 山火贲 → 山雷颐 → 山风蛊 → 山天大畜 → 艮为山 → 山水蒙。
- 对应剧情结构：
  - 山体剥落。
  - 队伍损耗。
  - 壁画与古城之美。
  - 山中巨口与培育设施。
  - 古代腐败复发。
  - 发现敦威治不是唯一案例；远古 / 古代已有“人类 / 灵长类作为外神胚胎或温床”的现象。
  - 抵达不可越之止境。
  - 跨越世界不允许越过的高维边界。
  - 发现此前的认知只是“启蒙”。
  - 发现若干星宿封印已经回归 / 变化。
  - 启程调查坎卷封印。
- 与坎卷的结构衔接：
  - 艮卷侧重山经。
  - 坎卷侧重海经。
