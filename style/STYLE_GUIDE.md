# 14. Style and Tone

## [CONFIRMED]
- 网文长篇结构。
- 中西神话 / 神秘学融合。
- 不是单纯“道士打古神”。
- 八卦、山海经、二十八宿、克苏鲁神话应作为同一大世界结构中的不同解释 / 表现层。
- 各卷通过卦象结构形成叙事逻辑，而非仅作为卷名装饰。
- 第一卷有双时间线交叉叙事。
- 1928 与 2026 应互相提供对方无法获得的信息。
- 第二卷使用现代科技条件重写《疯狂山脉》式探索，而不是直接复制原作年代背景。
- 恐怖尺度逐卷扩大：
  - 第一卷偏生命 / 繁衍 / 乡野。
  - 第二卷偏山岳 / 古文明 / 人类来源。
  - 后续扩展至深海、信息、时间、恒星、梦境、混沌。

## [PROPOSED]
- 恐怖表现可避免简单能量战斗，更多采用：
  - 生殖 / 生物恐怖。
  - 认知恐怖。
  - 时间与身份错位。
  - 档案与历史不一致。
  - 高维空间。
  - 信息污染。
- 主角能力成长以“理解宇宙规则 / 获得更多操作权限”为主，而不是单纯数值升级。
- 每卷应形成独立悬疑事件，同时推进 2048 主线。
